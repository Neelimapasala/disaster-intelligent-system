## 📌 Overview

AI-powered disaster intelligence system built in Python and deployed as a web app.

## 📂 What's inside

| File | Purpose |
|---|---|
| `app.py` | Application entry point |
| `complete_system.py` | Core system logic |
| `requirements.txt` | Python dependencies |
| `render.yaml`, `runtime.txt` | Deployment configuration for Render |

## 🚀 Run locally

```bash
pip install -r requirements.txt
python app.py
```
